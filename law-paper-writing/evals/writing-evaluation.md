# 正文写作评阅与对照方法

## 目的与隔离

测试实际生成或修改正文的能力。保留原有 [压力场景](pressure-tests.md)、[论证诊断场景](argumentation-cases.md) 和 [融合场景](generic-fusion-cases.md)，不把新增任务数当通过率。

执行者只读取 [写作输入](writing-inputs.md) 中一个任务及对应版本的技能和所需参考文件，不读取本文件、示例答案或其他版本输出。这里的“示例答案”指评测答案；技能自带教学示例属于被测内容。教学示例与测题题材不同，避免直接复述。评阅者在输出完成后读取材料、标准与匿名文本。

## 正文判断

每项给出通过、部分满足、未满足或不适用，并附具体句段和理由；不把总分替代实质判断。

| 维度 | 查看正文中的什么 |
|---|---|
| 推论 | 关键结论依赖什么前提；材料到判断之间是否有可复核的理由 |
| 法律与建议的区分 | 是复述合成规则、提出解释还是制度建议；有没有把目标直接写成现成义务 |
| 对不同解释的回应 | 是否准确呈现材料支持的竞争解释，并说明它使结论受到什么限制 |
| 段落推进 | 连续句段是否增加理由、证据、区分或必要限定；是否反复换词重述一个判断 |
| 作者原意 | 修改是否改变主体、条件、范围、语气强弱和有意保留的措辞 |
| 来源 | 材料编号和原文内容是否对应；有无新增事实、虚构引用或把假设当真实法律 |
| 连续阅读 | 能否说清作者在证明什么；表达是否具体、术语是否稳定，是否塞入未完成的检查报告 |

“首先”“因此”等词、先提出结论、整齐标题、合法技术术语本身不算失败。允许必要的主题句和简短回顾。不能用禁词命中数、随机句长、AI 检测分数或“猜作者是不是人”决定胜负。

## 任务观察点

- **W1**：说明已知结果与识别错误事实之间的差别；回应猜测并提交全部材料的解释，指出其仍不能保证有针对性地提出更正；不把“必须逐项指出事实”加进合成规则，不把作者推论说成明文义务；限定全部内部讨论的公开范围。不强塞案例或统计。
- **W2**：书面材料在六例中并非支持申请的必要条件或充分条件；事实核对与结果在所选材料中共同出现，但不能据此证明因果、法定义务或总体趋势；处理 C4、C5，保留样本选择和其他差异的限制。不可把有意选择的六例外推为普遍倾向。
- **W3**：保留作者的具体疑问、有限立场与研究边界；可以指出“提出申请”到“获得纠错机会”之间的理由。原稿把作者暂不讨论的问题标给 R2 第2段，应分清“材料未规定”与“作者不讨论”，使引注对应。无需凭空增加案例、改革框架或更强结论；有效原句可以保留。
- **W4**：这是先提出判断、随后给理由的合理写法；必要条件与结果保证已区分。无需按材料归纳重排、补真实判例或虚构反方。允许提出不改变判断的可选措辞建议，但不能把它称为必须修复的缺陷。

## 最小对照与记录

计划性对照可取 W1—W3，各用现版/候选版在全新上下文生成两次，共十二份正文；W4 作为合理写法保护场景另测。使用同一模型配置和同一任务文本，记录技能提交或内容哈希、实际加载路径、材料、执行日期、执行者标识、可知的模型设置及完整输出；无法读取的设置标为未知。可增加无写作技能的控制组，检查改动是否有超过模型原有能力的收益。

由未参与写作的评阅者随机匿名比较，允许平局，记录偏好的具体理由；作者或法学读者复核语义与表达。没有独立评阅者时标为维护者评阅，不称盲测。合成题无法验证真实来源核验能力，仍需保留相关压力测试。

小样本只能筛选改动方向。拟发布前再用用户授权的完整稿件，检查跨章节重复、概念漂移和结论超范围。工作稿可如实留下待核标记；评价表达改善不能升级来源状态。

执行记录应明确哪些已经运行、哪些仅为后续计划；没有实际输出的任务不能写通过。若现版或无技能控制已经写得合理，照实记为未观察到该缺陷，不制造失败或声称候选版显著优越。
