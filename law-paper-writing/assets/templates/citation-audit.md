# 引注审核

- [ ] 每项来源性主张后均有对应标识
- [ ] 正文标识与脚注双向对应
- [ ] 每条脚注能追到来源编号和原始资料
- [ ] 来源登记中的完整著录、原始位置、精确定位、核验日期和允许用途完整
- [ ] 最终稿所用来源均为 `VERIFIED`，无 `PARTIAL`、`LEAD_ONLY` 或 `UNUSABLE`
- [ ] 直接引语均有精确位置
- [ ] 转述、二手转引和译文均已说明
- [ ] 法律规范版本及效力已经核验
- [ ] 案件名称、案号、法院和日期已经核验
- [ ] 数据口径、范围、时间和发布者完整
- [ ] 无孤立参考文献或脚注
- [ ] 适用的必填字段完整；不适用的条件字段明确标注 `N/A` 并说明依据；可选备注可留空
- [ ] 无虚构字段、`[待核]`、待补充或待核验等未完成占位
- [ ] 适用引注体例已确定：目标期刊正式要求、用户确认体例或手册默认工作体例；差异已说明
- [ ] 再次引用可准确回到首次引注；未定稿不提前略写，改号后交叉核对
- [ ] 标点、文号、书名号和外文斜体一致，格式调整未改变原始标识或掩盖来源缺口
