# 写作技能更名与日期版本（Bundle v2610.9）

## 目标

1. 把上游 [VictorTran1023/law-paper-writing-skill](https://github.com/VictorTran1023/law-paper-writing-skill) v1.4.0（提交 `7a9ad004`，涵盖其 1.2.0 / v1.3.0 / v1.4.0 改进）增量并入写作技能；
2. 写作技能正式名称由 `chinese-law-paper-writing` 改为 `law-paper-writing`（显示名 Law Paper Writing）；其余两个技能名称不变；
3. 三个技能与技能包自本版起按日期编号：公开标签 `vYYMM.D`（首版 `v2610.9` = 2026-10-09），机器字段 `YYMM.D.N`（`2610.9.0`）；
4. 更新器支持旧名原位迁移与日期版本，保证已安装用户的一次性迁移路径可用、可回滚。

## 关键决定

| 问题 | 决定 | 理由 |
|---|---|---|
| 上游并入方式 | 增量并入、章节级协调；保留本技能包独有层（DOCX 真实脚注、实证统计、note-level 溯源、更新器、稿件管理） | 双方是各自独立演化的两条线，整目录覆盖会丢能力；逐文件处置表见 `law-paper-writing/references/upstream-integration.md` |
| 上游开发计划是否装入 | 不装入运行技能 | 改进已进入参考文件与评估场景；开发计划不作为执行指令，也避免携带机器路径 |
| 更名范围 | 目录、frontmatter、宿主提示、插件清单、README 安装入口、跨技能引用、更新器、清单与锁文件同步；历史记录保留旧名 | 更名按迁移处理，不是文件夹改名；活动引用用新名，历史记录与迁移别名保留旧名 |
| 版本格式 | 公开标签 `vYYMM.D`；机器字段保留三段数字 `YYMM.D.N` | 宿主与更新器按三段数字比较；同日追加发布递增 N；历史版本号原样保留，论文稿件版本不随此规则 |
| 旧安装升级 | 旧更新器拒绝新清单 → 用新版脚本做一次性 bootstrap（README“一次性升级”说明）；Hermes Hub 旧名登记 fail-closed | 旧脚本写死的技能集合无法透明识别新名；不承诺旧脚本自动升级，也不假装已完成改名 |
| 迁移安全 | 旧名目录原地改名（保留分类目录）；先完整备份、失败回滚；本地修改与缺失技能独立确认；符号链接、Git 工作树、插件目录拒绝写入 | 与既有安全门禁一致；防止写穿符号链接或留下失配的 Hub 记录 |
| 测试夹具的临时路径 | 统一改为规范化（不含符号链接）路径 | 更新器按设计拒绝含符号链接的祖先目录（含 macOS 的 `/var`）；夹具必须给规范化路径，否则 macOS 默认环境下整批误报 |

## 验证

- `python3 -X utf8 -m unittest discover -s tests -v`：147 项全部通过；macOS 默认 TMPDIR 与受控 TMPDIR 两种环境结果一致；
- Python 3.9（系统 `python3`）AST 解析全部涉改脚本与测试文件；发布工具 `--check` 与更新器 `check` 可在 3.9 直接运行；
- `python3 tools/prepare_bundle_release.py --check`：`Bundle 2610.9.0 is consistent`（3.11 与 3.9 均通过）；
- Codex `quick_validate.py`：三个技能均通过（`Skill is valid!`）；
- 真实源码树冒烟：以 2026.0928.0 基线的旧安装（旧名位于分类子目录）对最终发布产物执行迁移——预检 `clean` → `apply` 后 `updated`，`check` 为 `up_to_date`；注入故障后 `rolled_back`，旧目录字节级还原；无关技能目录与 `raw/` 研究材料完全未动；
- 三份更新器字节一致；清单 118 个文件，历史链 `[1.0.0, 2026.0925.0, 2026.0928.0, 2610.9.0]`；
- 更新器按 TDD 开发（RED/GREEN 过程日志与交接记录留在开发工作目录，不入库）；
- 未在本轮运行：`claude plugin validate`（本机未安装 claude CLI）；插件清单结构由兼容性测试覆盖。

## 迁移提示（面向已安装用户）

- 源码复制安装：用新版 `scripts/legal_skills_update.py` 对暂存的新版包执行 `apply`（含 `--allow-local-changes`），旧名目录原位改名并更新；
- Hermes Skills Hub 登记旧名的用户：按宿主的卸载/重装方式一次性转换后再更新；
- 插件安装：`claude plugin update` 即可，不涉及目录迁移。
